# 양자컴퓨팅 이론 및 실습 (12시간 집중 부트캠프) - Day 1

본 저장소는 **[양자컴퓨팅 이론 및 실습]** 4주(총 12시간) 집중 강좌 중 **1주차 (Day 1: 단일 큐비트와 상태벡터)** 공식 학생용 실습 및 배포 저장소입니다.  
강의 슬라이드, Day 1 렉처노트 및 실습 파일(Jupyter Notebook), 원클릭 구동 스크립트가 포함되어 있습니다.

- **강사**: 서상협 ((주)큐렌스 / QRens)
- **주제**: 1주차 - 단일 큐비트와 상태벡터 (Pure NumPy 기초 실습)
- **사전 요구사항**: 기본적인 파이썬 문법 이해 (컴퓨터에 파이썬이 설치되어 있지 않아도 아래 원클릭 실행기로 자동 세팅됩니다!)

---

## 📥 저장소 다운로드 (2가지 방법 중 선택)

### 방법 1. Git 사용 (추천 - 복사해서 터미널에 붙여넣기)
터미널(또는 Git Bash, PowerShell)을 열고 아래 명령어를 입력하여 저장소를 복제합니다:

```bash
git clone https://github.com/saibie/quantum-computing-bootcamp-2026-day1.git
cd quantum-computing-bootcamp-2026-day1
```

### 방법 2. ZIP 파일 다운로드 (Git 미설치자 / 초보자용)
1. 페이지 우측 상단의 초록색 **`Code`** 버튼을 클릭합니다.
2. **`Download ZIP`**을 선택하여 압축 파일을 다운로드합니다.
3. 다운로드한 파일의 **압축을 해제**한 후 해당 폴더로 들어갑니다. (※ 압축 해제 필수!)

---

## 🚀 3초 만에 실습 환경 시작하기

파이썬 설치 버전 충돌이나 가상환경 설정 번거로움 없이, 초고속 패키지 매니저 `uv`가 파이썬(Python 3.12)과 필수 라이브러리(NumPy, Qiskit, Jupyter Lab)를 격리된 전용 환경에 즉시 세팅해 줍니다.

### 🪟 Windows 사용자
1. 폴더 내의 **`start_windows.bat`** 파일을 더블 클릭하여 실행합니다.
2. 검은색 터미널(CMD) 창이 뜨고 패키지 자동 설치가 진행됩니다. (※ 실습 중 이 창을 닫지 마세요!)
3. 잠시 후 기본 웹 브라우저에 **Jupyter Lab** 실습 화면이 자동으로 열립니다.

> **참고**: Windows 보안 경고(SmartScreen)가 뜨는 경우, `추가 정보` 클릭 후 `실행`을 눌러주시면 됩니다.

---

### 🍎 macOS 및 Linux 사용자
1. 터미널을 열고 저장소 폴더로 이동합니다.
2. 아래 명령어를 실행합니다:
   ```bash
   chmod +x start_mac.sh
   ./start_mac.sh
   ```
3. 자동으로 필요한 환경이 구성되고 브라우저에 **Jupyter Lab**이 실행됩니다.

---

## 🛠️ 수동 명령어 실행 (터미널/CLI 사용자)

이미 `uv`가 설치되어 있거나 터미널 사용이 익숙하시다면 아래 명령어로 직접 구동할 수 있습니다:

```bash
uv sync
uv run jupyter lab --notebook-dir=hands_on
```
